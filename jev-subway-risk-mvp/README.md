# Jev 서울 지하철 사고위험 분석 MVP

업로드된 서울교통공사 최근 5년 지하철 사고 CSV를 이용해 출발역·도착역·시간대별 역사적 사고 신호를 계산하고, TypeSafe Jev에 Noul과 Score 질문을 보내는 최소 실행 환경임.

## 실행

```bash
cp .env.example .env
# .env에 TYPESAFE_API_KEY 입력
node server.mjs
```

브라우저에서 `http://localhost:3000` 접속함.

현재 서버는 `.env`를 자동으로 읽지 않으므로 먼저 셸 환경변수로 내보내야 함.

```bash
export TYPESAFE_API_KEY='발급받은 키'
node server.mjs
```

## 현재 분석 방식

1. 경로에 포함된 역의 전체 사고건수를 계산함.
2. 선택 시간 ±1시간에 발생한 사고건수를 계산함.
3. 위 통계와 경로·시간을 Jev에 전달함.
4. Noul은 “역사적 평균보다 사고위험이 높은가?”에 대한 0~1 값을 반환함.
5. Score는 영향도를 낮음·중간·높음의 확률가중 점수로 반환함.

## 중요한 한계

현재 데이터에는 역별 승객 수, 시간대별 승객 수, 열차 운행 횟수, 노선·환승 경로가 없음. 따라서 결과는 실제 개인 이동의 절대 사고확률이 아니라 역사적 사고기록 기반의 상대위험 신호임.

실제 위험확률로 발전하려면 승객 통행량 또는 운행횟수를 분모로 추가하고, 노선 그래프와 이동시간을 연결해야 함. 이후 과거 데이터를 학습·검증용으로 나누어 Jev의 Noul 값을 calibration test하는 과정이 필요함.
